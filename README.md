# Mercado Inteligente
 
Sistema de gerenciamento de mercado com interface gráfica Swing.
 
## Funcionalidades
 
- CRUD completo de Produtos
- Criação de Delivery com verificação de estoque
- Listagem e exclusão de Deliveries
- Command Pattern e Decorator Pattern
 
## Tecnologias
 
- Java 21
- Swing
- JDBC + MySQL
- Design Patterns: MVC, DAO, Command, Builder, Decorator
 
## Como Executar
 
1. Clone o repositório
2. Execute o arquivo `banco.sql` no MySQL
3. Atualize usuário/senha no `ConexaoUtil.java`
4. Dê duplo-clique em `run.bat`
